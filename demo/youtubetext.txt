Install Phil's tools is one program that installs, updates and removes all of Phil's Paratext plugins. The CMS checks come with the Phils Custom (cms) Checks plugin. Download it once, tick the tools you want, and click Install. It finds every Paratext 9 on the computer and checks each file before installing it.
