==============================================================================
 Install Phil's Paratext tools - Change log
 Generated November 18, 2026
==============================================================================

What changed in Install_Phils_tools.exe and in each plugin it installs, newest
first. Versions with no recorded changes are left out.

INSTALLER (Install_Phils_tools.exe)
-----------------------------------
2.6  (November 18, 2026)
  * Windows asks for administrator permission at most once for all the ticked
    plugins, instead of once per plugin (for example with Paratext 9 Beta
    installed).
2.5  (November 18, 2026)
  * Smaller: the installer no longer carries copies of the old CMS checks,
    which it has not installed since 1.3. "Remove old CMS copies..." still
    finds and removes them.
  * The program's file properties now show its real version and SIL Global.
  * These changes are meant to keep Windows Defender from wrongly reporting
    the installer as a threat, as it did with 2.4.
2.4  (November 17, 2026)
  * Carries Phils Custom (cms) Checks 1.8.
  * The description of Phils Custom (cms) Checks now says the checks come in
    English, Spanish and French.
2.3  (November 17, 2026)
  * Carries Phils Custom (cms) Checks 1.7.
  * This change log (Install_Phils_tools_ChangeLog.txt) now comes with the
    installer.
2.2  (November 13, 2026)
  * Carries Phils Custom (cms) Checks 1.6 (all checks in French too).
2.1  (November 13, 2026)
  * The window widens itself so that all its buttons fit ("User guide" was cut
    off in Spanish and French).
  * The installer has its own user guide in English, Spanish and French.
2.0  (November 13, 2026)
  * Installs the plugins by itself, without PowerShell. Windows Defender had
    quarantined version 1.9 as a Trojan because it started PowerShell in the
    background.
  * When administrator rights are needed, the Windows prompt now names
    Install_Phils_tools.exe.
1.9  (November 13, 2026)
  * Carries Parallel Passages Editor 1.3 (adding your own passages).
1.8  (November 13, 2026)
  * Carries Special Features 1.7.
1.7  (November 12, 2026)
  * Carries AutoCorrect Editor 1.1.
1.6  (date not recorded)
  * User guides open in the installer's own viewer, so they can be read
    without Word or WordPad (Windows 11 no longer has WordPad).
1.5  (date not recorded)
  * New "User guide" button: opens the selected plugin's guide in the window's
    language.
1.4  (date not recorded)
  * A note at the top says that the CMS checks are now installed as Phils
    Custom (cms) Checks.
  * A click anywhere on a row ticks or unticks it.
1.3  (November 11, 2026)
  * The CMS tab was removed: the checks now come with the Phils Custom (cms)
    Checks plugin.
  * The plugins are listed in alphabetical order in the window's language.
  * Old copies of the checks in a cms folder can be removed ("Remove old CMS
    copies...").
  * Project Checker's launcher is no longer offered.
1.0  (November 9, 2026)
  * First version: one program that installs, updates and removes all the
    plugins, and shows whether each one is installed or has an update.
